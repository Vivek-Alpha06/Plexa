# Activity exports

Generated by `scripts/export-activity.mjs` — every row is read from the Stellar
ledger, and every transaction hash resolves on a block explorer.

| File | Contents |
|---|---|
| `activity.csv` | Every recorded action: wallet, group, action, amount, timestamp, tx hash, explorer link |
| `wallets.csv` | One row per distinct wallet with its activity count and first/last seen |
| `activity.md` | The same data as a markdown table, ready to paste into a README |

Regenerate with:

```bash
node scripts/export-activity.mjs
```

Soroban RPC serves contract events for a **rolling window of roughly a week**.
The history log inside each contract is permanent, but it carries no
transaction hashes — a contract cannot know its own hash — so the pairing of
action to hash only exists while the events are still served. Run the export
regularly and the archive keeps extending itself; skip it for a fortnight and
that week's hashes are no longer recoverable.
